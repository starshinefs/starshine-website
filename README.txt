STARSHINE WEBSITE - UPLOAD TO HOSTINGER
1. Log in to Hostinger > Websites > Manage (your domain) > Files > File Manager.
2. Open the public_html folder. Delete the default index/default.php file if one is there.
3. Click Upload and choose starshine-website.zip, then right-click it > Extract (into public_html).
   Make sure index.html and the images folder sit directly inside public_html (not in a sub-folder).
4. Visit your domain. Done.

REPLACING PHOTOS
The photos in /images are low-resolution crops from the mockup. Replace them with your own
high-quality photos using the SAME file names (hero.jpg, standard.jpg, deep.jpg, tenancy.jpg,
builders.jpg, airbnb.jpg, kitchen.jpg). Landscape JPGs around 1600px wide (hero) / 800px (cards) work best.

EDITING TEXT
Open index.html in File Manager (right-click > Edit). Phone, email, company details and
reviews are plain text you can change. The "See more reviews on Google" and social icon links
are set to "#" - paste your real Google/Facebook/Instagram links in their place.
The quote form opens the visitor's email app addressed to info@starshinefs.co.uk.
